# astro-search

Локальний сайт у Docker-контейнері для фото нічного неба. Він знаходить зорі на кадрі, визначає, куди дивилася камера (plate solving), підписує зорі, планети й Місяць і показує, наскільки точний результат.

Поки що проєкт на етапі задуму. Ідеї, архітектура й уже перевірені результати описані в [IDEAS.md](IDEAS.md).
